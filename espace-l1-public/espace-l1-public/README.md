# Espace L1 Droit

Mon espace de travail pour la Licence 1 de droit à l'IED Paris 1 (2026-2027) : planning, devoirs, to-do, documents de cours, codes et textes officiels, semaine type et sorties.

C'est un site d'une seule page (`index.html`), sans installation. Les coches, statuts et ajouts sont enregistrés **dans le navigateur** qui ouvre la page (ordinateur et téléphone ne se synchronisent pas).

## Mettre le site en ligne avec GitHub Pages

1. Crée un compte sur https://github.com si tu n'en as pas.
2. Clique sur **+** en haut à droite → **New repository**.
   - Nom : `espace-l1` (par exemple).
   - Visibilité : **Public** (gratuit).
   - Ne coche rien d'autre, clique sur **Create repository**.
3. Sur la page du dépôt vide, clique sur **uploading an existing file**.
4. Glisse **tout le contenu** de ce dossier (le fichier `index.html`, le fichier `.nojekyll`, ce `README.md`) dans la zone, puis clique sur **Commit changes**.
   - Sur Windows, `.nojekyll` est un fichier caché : active « Éléments masqués » dans l'Explorateur (onglet Affichage) pour le voir. S'il manque, le site marche quand même.
5. Va dans **Settings** → **Pages** (menu de gauche).
6. Sous **Build and deployment**, choisis **Deploy from a branch**, puis la branche **main** et le dossier **/ (root)**. Clique sur **Save**.
7. Attends 1 à 2 minutes et recharge : l'adresse du site s'affiche en haut de la page Pages, du type `https://ton-pseudo.github.io/espace-l1/`.

## Mettre à jour plus tard

Dans le dépôt : **Add file** → **Upload files**, glisse le nouveau `index.html`, puis **Commit changes**. Le site se met à jour en une minute environ. Tes coches restent dans ton navigateur.

## À savoir sur cette version publique

- Elle **ne contient pas les cours de tes profs** : les documents renvoient vers la plateforme IED (il faut y être connecté pour les ouvrir). Les cours appartiennent à l'université et ne doivent pas être diffusés publiquement.
- Les adresses mail des enseignants ont été retirées.
- Le site est public : toute personne qui a le lien peut le voir. Il est marqué pour ne pas apparaître dans Google, mais ce n'est pas une protection. Ton planning de streams et tes sorties y figurent : enlève-les si tu ne veux pas qu'ils soient visibles.
